# Ambient Sounds Directory

This directory contains ambient sound files for the Pomodoro timer application.

## Required Sound Files:

### forest.mp3
- Gentle forest ambiance with birds chirping
- Duration: 2-3 minutes (loopable)
- CC0 Licensed

### ocean.mp3
- Ocean waves crashing sound
- Duration: 2-3 minutes (loopable)
- CC0 Licensed

### cafe.mp3
- Coffee shop background noise
- Duration: 2-3 minutes (loopable)
- CC0 Licensed

### rain.mp3
- Rain falling sound
- Duration: 2-3 minutes (loopable)
- CC0 Licensed

## Sources for CC0 Licensed Sounds:

- Freesound.org (filter by CC0 license)
- Zapsplat (free registration required)
- BBC Sound Effects (CC0 licensed collections)
- YouTube Audio Library (download and convert)

## Audio Requirements:
- Format: MP3 or OGG
- Sample rate: 44.1kHz
- Bitrate: 128-192kbps
- Loopable: Yes (seamless looping)
- File size: Under 2MB per file
